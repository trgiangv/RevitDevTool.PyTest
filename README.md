# RevitDevTool.PyTest has moved

`revitdevtool-pytest` is now developed and released from
[trgiangv/RevitDevTool](https://github.com/trgiangv/RevitDevTool/tree/develop/source/RevitDevTool.PyTest).
This repository is archived.

- Install: `pip install revitdevtool-pytest` ([PyPI](https://pypi.org/project/revitdevtool-pytest/))
- Docs: [pytest](https://trgiangv.github.io/RevitDevTool/docs/testing/pytest)
- Changes: [CHANGELOG.md](https://github.com/trgiangv/RevitDevTool/blob/develop/source/RevitDevTool.PyTest/CHANGELOG.md)
- Issues: [trgiangv/RevitDevTool/issues](https://github.com/trgiangv/RevitDevTool/issues)

Releases from `0.6.1` on are published by `release.yml` in RevitDevTool, so PyPI shows a one-time change of
provenance against `0.6.0`.
